The network projects focuses on assignments from my network class in my education, as well as any personal research I've done. The class lasted for 10 weeks and contained a mix of lectures, assignments to build various virtual networks in Cisco Packet Tracer, physical presentations, and industry-standard documentation. Our teacher was a 5-year veteran penetration tester and we got a lot of insight into the cybersecurity industry, as well as some optional assignments about sniffing and cracking WPA2 keys, Linux CLI, as well as setting up a virtual machine Ubuntu Server and hardening it. None of the above was included in the course goals. We covered a lot in this class, included but not limited to:

- IP fundamentals, bits, binary numbers and subnetting
- The OSI model
- Selection of hardware, and the physical layer (L1) - how to connect devices
- Cisco CLI
- Data link layer (L2), how switches work, BPDUs, STP, trunking
- Network layer (L3), routing protocols RIP and OSPF, creating virtual ports, DHCP
- Firewalls, the different kinds and how they are applied, ACL
- VPN, what they are and how they increase security through encryption
- Wireless communication, encryption standards

The packet tracer files and attached documentation are assignments we got through the course that I have recreated to explore networking concepts. 

In the documentation, there are questions that show up in *cursive* text. These are questions that I've had to reflect on, which provides context to previous text.
